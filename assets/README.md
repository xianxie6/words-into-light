# Sample artwork

Vincent van Gogh, **Self-Portrait**, 1889. Musée d'Orsay.

Source: [Wikimedia Commons / Google Art Project](https://commons.wikimedia.org/wiki/File:Vincent_van_Gogh_-_Self-Portrait_-_Google_Art_Project.jpg).

The source identifies the painting and its faithful reproduction as public domain. This project bundles the 1200 px image as a local demonstration asset. Visitor-uploaded images remain in that visitor's browser and are not included in the repository or transmitted to a server.
